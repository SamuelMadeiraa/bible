Projeção fechada

Clique = prévia • Duplo clique = ao vivo • Shift+clique = intervalo

PRÉVIA
AO VIVO—

Clique nas palavras (aqui ou na prévia) para destacar com a cor selecionada. Setas ←/→ trocam de versículo (funciona com passador de slides).

Com 2 monitores (ou projetor/TV no HDMI), a projeção abre em tela cheia no monitor escolhido. Com um só monitor, abre em janela — use F11 ou duplo clique nela para tela cheia. Configure o Windows em Estender estas telas (Win+P).

OBS: Fontes → + → Navegador → cole o link, largura 1920, altura 1080.
Outro PC/TV na mesma rede Wi-Fi: abra o link no navegador e dê duplo clique para tela cheia. Se o Windows perguntar sobre o firewall, permita o acesso em redes privadas.
